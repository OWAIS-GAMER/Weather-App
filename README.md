Weather App

A responsive weather application that provides real-time weather information through a clean, modern, and user-friendly interface, built using HTML, CSS, and JavaScript.

Live Demo

"View Website" (https://weather-by-owais.netlify.app/)

Features

- Responsive design for mobile, tablet, and desktop
- Clean and modern user interface
- Weather information display
- Simple and user-friendly navigation

Technologies Used

- HTML5
- CSS3
- JavaScript

Run Locally

1. Clone this repository:
   
   "git clone https://github.com/OWAIS-GAMER/Weather-App.git"

2. Open the project folder.

3. Open "index.html" in your browser.
